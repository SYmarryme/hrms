# T-004 文件准备计划

依据：批准 tasks v1.4 的 T-004、架构 v1.2 §2/§10、ADR v1.2 §3/§5。
T-001～T-003 已获用户验收；本次仅编写文件，不在 Windows 安装或运行项目。

1. 独立 `experiments/t004/` Vue/TypeScript/Vite + FastAPI 健康检查夹具，
   不创建 HRMS 业务/认证/恢复能力，不读取私有交接包或业务数据库。
2. `scripts/m00/setup_t004.sh` 在忽略的随机目录建立独立 Python/前端安装环境，
   保存真实版本与候选锁；不改变已通过的 M00 锁、`.venv` 或项目源目录。
3. `start_t004.sh` 只绑定后端 127.0.0.1:8000、前端 0.0.0.0:3000。
   仅白名单公网 Host；禁止将仓库/私有资料作为 Vite 文件服务根目录。
4. `t004_probe.py` 检查 TLS、同源响应、伪造转发头拒信、诊断 Cookie 属性/Path、
   版本一致性；浏览器页面另验证真实浏览器 Cookie 行为。8000 外网暴露独立人工负测。
5. `t004_persistence.py prepare/verify` 在指定绝对目录中新建实验文件库，
   外存回执前后比对，验证跨工作空间暂停/重启的逻辑内容与完整性。
6. `docs/t004-execution.md` 提供准确分阶段命令、反例、证据与失败退出解释。
   `docs/t004-acceptance.md` 所有运行项保持 NOT_RUN。完成静态和独立审查后提交推送。

选择：采用隔离的最小健康检查夹具，使测试脚本可直接在云端执行；不先搭 M01 工程。
所有持久化写入只由受控实验 CLI 完成，公网端点全部 GET，只提供非敏感诊断。
转发信任策略：不自动信任 CloudStudio 或客户端带入的 Forwarded/X-Forwarded-*；
Vite 清除它们并使用操作者明确配置的 HTTPS origin；Uvicorn 禁用 proxy headers。
这验证固定同源入口策略，不声称已经确定平台客户端 IP 或任意多级代理信任链。

审查重点：私有路径不能通过 /@fs 读取；进程不杀既有服务；配置/数据目录不可误指业务；
成功 HTTP 状态不足以证明 8000 未曝光；进程重启不冒充工作空间重启；新依赖未执行不称锁定。

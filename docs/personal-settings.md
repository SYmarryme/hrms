## 功能与使用

- 右上角账号区域打开菜单，仅“设置”和“退出登录”。点击外部、切页及 Esc 关闭；方向键、Home/End 和 Enter 可操作。退出仍调用真实会话撤销。
- 设置通过 `/settings` 打开独立标签，不加入业务菜单、工作台快捷入口，不改变默认工作台。个人信息读取本人 `/auth/me`，只读展示用户名、角色、状态、绑定员工姓名及工号；未绑定员工显示“未绑定员工”。
- 账号安全提供当前密码、新密码、确认新密码三行表单，每行标签在左、同宽输入框在右，三个显隐按钮独立工作。密码沿用 12–128 字符及 Argon2id。取消清空输入，不请求改密；切换离开设置也清空密码草稿。
- 改密成功后全部旧会话撤销，回到登录页，使用新密码重新登录。错误当前密码、确认不一致、长度不合规及新旧相同均不修改密码或撤销正常会话。保存中锁定表单并阻止重复提交。
- ADMIN 创建账号或重置密码后，该账号须改密。受限登录只能取得必要的本人身份、改密或退出；不能读取或写入业务。全屏原生模态无关闭 X，Esc/遮罩无效，焦点限制在弹窗中。刷新及直接打开 URL 丢弃内存凭据，重新使用临时密码登录仍进入改密流程。
- 强制流程不挂载业务页面，不提前请求业务数据。背景仅保留应用外壳与无敏感内容的占位；这与参考图中灰暗的完整工作台有意不同。
- 沿用随机不透明 Bearer、私有 JavaScript 内存及服务端会话。30 天绝对期限、24 小时空闲期限、最多 5 个会话及 5 分钟更新节流不变。没有 Cookie/JWT/refresh/persistent Token。

## API 与后端约束

新增 `POST /api/v1/auth/password`（同源、Bearer）。JSON 只允许 `current_password`、`new_password`、`confirm_password`；不接收账号标识，拒绝额外字段及查询参数。成功返回 204，不回传密码或凭据。

登录及本人身份增加布尔 `must_change_password`。所有业务服务共用的会话解析器每次读取当前标记；受限状态返回 403 `PASSWORD_CHANGE_REQUIRED`，前端销毁旧业务缓存并进入强制流程。无效或撤销会话仍为 401，普通权限拒绝仍为 403。

`BEGIN IMMEDIATE` 将当前凭据核验、版本校验、Argon2id 更新、清除标记、撤销全部会话和成功审计放在一个事务中。并发改密只允许一个成功；审计异常使整个操作回滚。独立限流防止反复尝试当前密码。失败审计仅含账号引用、请求编号和固定原因码；不保存请求体、密码或 Token。管理员重置沿用版本控制、权限及审计，并原子撤销目标会话。

受控 CLI 重置和首次 HR 临时密码也标记需改密。原首次 ADMIN 自主选择密码、隔离测试中代表既有账号的 fixture 不冒充管理员创建的新账号。
